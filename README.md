# 申论复盘一体版

这是一个面向申论学习者的题目解析与作答批改助手。它会先把题干拆清楚，再回到材料建立得分点，最后按考场答案的方式讲解、评分和修改。

适用于归纳概括、综合分析、提出对策、贯彻执行、申发论述等题型，也支持整套试卷中的单题处理、参考答案对照、图片识别和 PDF 阅读。

## 先确定你要做什么

### 1. 只解析题目

适合你还没有作答，想先学这道题怎么审、怎么找点、怎么组织答案。

发送完整题干和对应材料：

```text
用申论技能解析下面这道题。

【题干】
……

【给定资料】
……
```

解析会完整讲清：题干责任、题型判断、方法名称和使用步骤、材料逐段找点、同类合并、字数压缩、考场组织、易错点和示范答案。题目没有提供分值时只解析，不擅自评分。

### 2. 批改考生作答

适合你已经写完答案，想知道得分、档位、具体缺口和怎么改。

```text
用申论技能批改下面的作答。

【题干】
……

【给定资料】
……

【考生作答】
……
```

批改不是只报一个分数，而是会先拆题，再逐句或逐条点评：

- 考生原句写了什么。
- 对应材料依据是什么。
- 命中了哪个要点。
- 是完整覆盖、部分覆盖、未覆盖还是表述不准确。
- 缺少什么关键限定。
- 为什么影响答案质量。
- 这一句可以怎样直接改写。

最后才给出档位、档内上位/中位/下位、建议中心值、合理区间和置信度。没有官方逐点细则时，会明确这是经验校准建议，不把模型估分说成官方扣分表。

### 3. 提供参考答案后批改

参考答案不是唯一标准答案，但能帮助稳定点池。推荐格式：

```text
用申论技能批改，并参考下面的答案。

【题干】
……

【给定资料】
……

【参考答案】
……

【考生作答】
……
```

处理时会先把参考答案当作候选骨架，再回到材料核对：

1. 参考答案有没有漏掉材料明确支持的点。
2. 参考答案有没有把同一功能的动作拆得过碎。
3. 参考答案中的表述是否超出材料。
4. 考生答案是否覆盖了材料点，即使没有使用参考答案的原词。

所以，考生不需要机械照抄参考答案。参考答案遗漏的材料点会补回；参考答案把研学、传承、文旅等同一功能拆成多个点时，会合并或标为可补充，不会因为不贴参考答案措辞就被明显压低。

### 4. 解析或批改整套试卷

如果上传整套 PDF 或长文字，但没有指定题目，建议先告诉我：

```text
这是整套申论试卷，先处理第 1 题。
```

这样会先定位对应题干、材料、参考答案和考生作答，再完整处理这一题。然后你可以继续说“解析第 2 题”或“批改第 2 题”。

如果你希望整卷逐题处理，也请明确说“按题号逐题完整解析”，不要只说“看看这套卷子”，这样可以避免先给一段材料概述而没有真正讲题。

## 不同题型怎么使用

### 归纳概括

适合“概括主要做法、经验、问题、成效、变化、启示”等题目。

重点是先判断题目要的是动作、问题、效果还是普遍启示，再把材料中的同功能内容合并。批改时会区分“前置概括词”和后面的具体动作：概括词略有偏差但后文准确，通常只提示表达优化，不会抹掉后文得分。

### 综合分析

适合词句理解、评价分析、解释观点、谈认识等题目。

不能只摘材料，也不能只写对策。通常要完成“解释含义—分析关系或原因—结合材料论证—提出做法或结论”的完整链条。批改会重点检查你是否解释了题眼、是否分析了关系、是否把材料事实转化成观点。

### 提出对策

先判断题目是要求“提出对策”，还是要求“概括某人如何解决问题”。前者可以提出针对性措施，后者主要概括材料中已经发生的做法，不能把自己的常识对策混进去。

### 贯彻执行

需要同时看文种、身份、对象、目的和格式要求。报告、倡议书、讲话稿、短评、案例摘要等写法不同。只有题目明确要求称谓、落款、日期等格式时才检查相应格式；格式不是题目要求时，不会用固定模板压低内容得分。

### 申发论述

大作文会先拆关键词和关系，再确定总论点、分论点和材料使用路线。批改时按自然段讲：段落功能、分论点与总论点的关系、论据是否完成“事实—分析—观点”转化、是否回应题干关系、如何修改。

不会只给“几类文、多少分”的结论，也不会只把全文总结成几句话。没有考生文章时给完整立意解析和示范文章；有考生文章时给逐段批改，参考答案或范文只作为校准，不会替代对文章本身的分析。

## 图片、PDF 和文字怎么发

### 图片

可以直接上传题目截图、答题纸照片或参考答案截图。请尽量保证题干、材料、答案和字数要求清晰。手写答案如果有看不清的字，会标记待核对，不会凭猜测判定材料外内容或漏点。

### PDF

可以直接上传整套试卷 PDF。若只想处理某一道，最好同时说明题号；若没有指定题号，会先帮你定位题目，不会把整套材料概括一遍就结束。

### 纯文字

文字版最适合批改。建议用以下结构：

```text
【题干】……
【给定资料】……
【参考答案】……（没有可省略）
【考生作答】……（做解析时可省略）
```

## 你会看到什么

一次完整的申论解析或批改，至少会回答：

- 题目到底问什么，哪些词决定答题方向。
- 方法叫什么，为什么适用，遇到同类题如何操作。
- 材料中每个核心点从哪里来，哪些内容应合并或舍弃。
- 考生每一句覆盖了什么，还缺什么，怎样改最直接。
- 答案是否把结果当做法、把背景当成要点或加入材料外内容。
- 大作文是否完成立意、分论点、论据和分析的闭环。
- 最终档位、档内位置、建议分数和改进优先级。

只要题干和材料齐全，最终会直接发送完整正文，不用“核心结论速览”、文件路径或几句话摘要代替解析。题目缺少材料、作答或关键图片时，才会明确说明缺什么。

## 常用口令

```text
用申论技能解析这道题。
用申论技能批改我的作答。
参考下面这份答案批改，但请回材料核验点池。
逐句点评我的答案，不要只给总评。
先详细拆题，再批改。
只看纯文字内容，不因标点、编号和排版扣分。
这是整套试卷，先完整处理第 1 题。
```

## 使用建议

1. 小题最好提供题干、对应材料和自己的答案，批改会更准确。
2. 参考答案可以提供多份，但普通练习提供一份可靠答案就够了。
3. 大作文最好同时提供题干、全部材料和完整文章，不要只发文章标题或提纲。
4. 如果只想学习方法，省略考生答案；如果想评分，必须提供完整作答。
5. 字数限制、分值、身份和文种会直接影响答案组织，尽量不要省略。

## 使用边界

申论评分没有统一公开的逐字逐点官方算法，建议分数用于定位问题和比较进步，不应替代真实阅卷分数。材料不完整、OCR 不清楚或参考答案与题目不匹配时，会保留不确定性，不为了给出确定分数而编造材料依据。

本仓库为个人私密使用的申论技能包。

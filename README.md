# 申论复盘一体版

申论材料精读、整卷解析、参考答案校准、考生作答评分、逐句诊断、二稿修改和学情复盘技能。

## 内容

- `SKILL.md`：技能入口与使用规则
- `references/`：题型原型、评分协议、方法卡、输入边界和输出规范
- `scripts/review_engine.py`：标准库实现的确定性评分与校验引擎
- `assets/`：报告输出模板
- `tests/`：回归测试

## 主要能力

- 归纳概括、综合分析、提出对策、贯彻执行、申发论述
- 无参考答案时独立建点，有参考答案时先做材料核验与点池校准
- 纯文字、图片、文档和 PDF 输入边界处理
- 参考答案、考生答案、字数和材料证据的统一审计
- 完整教学式解析与批改，避免只返回摘要

## 使用

安装时将本目录作为一个完整技能包使用。输入题干、对应材料和考生作答后，技能会按题型路由到解析或批改流程；提供参考答案时会先进行候选点池校准。

## 许可

本仓库为个人私密开发与复习使用。

## 已确认的行为原则

1. 题干和材料齐备时，无论解析还是批改，都必须在聊天框完整输出正文，不能只给总结、速览或文件路径。
2. 有参考答案时，参考答案是重要候选，仍需回材料核验；如发现遗漏、拔高或冲突，要说明材料依据和 AI 采用口径，但不能擅自降低参考答案权重。
3. 没有官方答案时，不把 AI 自拟答案伪装成官方标准，应说明是经验校准或材料独立建点。
4. 应用文格式只在题面明确要求时作为硬性要求，不能机械惩罚未明示的称谓、落款、日期等。
5. 前置概括词、标题词和编号本身不计分；字数紧时可以压缩，但不能影响实质要点判断。
6. 多主体互动题应检查“主体 A 行动—主体 B 响应—形成结果”的关系链，不能把双方做法简单并列后称为互动。
